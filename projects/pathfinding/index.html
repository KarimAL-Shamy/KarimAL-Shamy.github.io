How It Works

  • Click & Drag: Left-click and drag on the grid to position or move the Start (S) and Goal (G) markers.
  • Terrain Traversal: Agents can only navigate through tiles of the same terrain type as their starting location.
  • Multi-Size Footprint: Select 2×2 or 3×3 square agents. The algorithm uses precomputed cardinal BFS sectors to guarantee all tiles of the footprint stay within matching terrain.
  • Diagonal Clearance: 8-direction actions prevent corner cutting by checking both cardinal neighbor clearances before diagonal stepping.
  • Shortcuts: Space Pause/Resume, R Rerun, C Clear, S Single Step.
