# Karim Hassan - Personal Portfolio Website

A clean, modern, and high-performance developer portfolio website engineered with responsive UI/UX, smooth glassmorphism aesthetics, dynamic dark/light theme switching, and interactive canvas graphics.

## Features
- **Modern Responsive Design**: Dynamic layouts tailored for desktop, split-screen (half-screen), tablet, and mobile devices (iPhone, Android).
- **Interactive Particle Space Canvas**: Trigonometric particle system built with HTML5 Canvas and `pt.js`, auto-throttled with `IntersectionObserver` when scrolled off-screen.
- **Dark & Light Mode**: System theme auto-detection with persistent manual toggle and 0-flash rendering.
- **Project Showcase**: Live interactive demos for algorithm visualization, creative mathematics clock, and games.
- **Experience Timeline**: Staggered milestone cards for software engineering and academic roles.
- **Certificates Lightbox**: High-resolution certificate modal preview with direct external verification links.

## Quick Start (Local Run)
Simply open `index.html` in any modern web browser:
```bash
# Optional local static server
npx serve .
# or
python -m http.server 8000
```

## Hosting on GitHub Pages
1. Initialize git in this directory:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio website"
   ```
2. Create a GitHub repository (e.g., `username.github.io` or `portfolio`).
3. Link the remote and push:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub Repository Settings -> **Pages**, set source to `main` branch `/ (root)` and save.
